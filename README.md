# Catatan Haid

Pencatat haid, nifas dan istihadhah menurut mazhab Syafi'i (qaul tsani), dengan hitungan mandi, qadha shalat, prediksi haid, dan rujukan ke buku *Dan Mereka Bertanya Kepadamu Tentang Haid* (Nur Hasyim S. Anam) serta syair *Bait-Bait Haid*.

- Buka `index.html` di peramban, atau lewat GitHub Pages.
- Catatan setiap pengguna tersimpan di peramban perangkatnya sendiri (tidak dikirim ke server mana pun). Gunakan menu **Lainnya → Ekspor** untuk cadangan.
- Hasil aplikasi membantu menghitung, bukan pengganti bertanya kepada guru. Untuk keluhan kesehatan, periksakan diri ke dokter.
